# Sidebar arms: latency and workload tables (#832)

Companion to [controlled results](stream-sidebar-arms-measured.md). Each latency
cell is the median of logged per-window percentiles followed by min–max in
parentheses, in milliseconds; even-sized medians average the two middle values.
Values are rounded only after aggregation. No windows are discarded or pooled
into a new percentile. Workload counts are summed; T/E are counts passing
`costTargets` / `costRecommendable`, not the historical one-second verdict.

P99 = `Post` entry to return; R95 = post return to message send (the target
clock, possibly negative); S95 = scheduled post time to message send; F95/F99 =
post return to first sent sidebar snapshot covering count AND committed sequence,
per member. Initial setup is excluded. [Accounting totals](stream-sidebar-arms-accounting.md)
include posting plus drain. L is the pre-fix ladder at e7879c5; R is the corrected
60-second re-run at d0252bc; F is the five-minute async40 run at d0252bc.

Sources: the operator's local ladder, re-run and five-minute logs (not in the
repository; see the [summary](stream-sidebar-arms-measured.md)).
