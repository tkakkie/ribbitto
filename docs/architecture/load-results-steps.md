# Load results by step

Every step of #216's run of 2026-10-07, from the client's JSON output and the
2-second samples; the setup, workload and conclusions are in
[load results](load-results.md).

Steps are listed in run order:
- **Series:** each series started on a freshly restarted server.
- **Reruns:** the reruns sampled CPU per interval.
- **Pool 40:** the server used `pool_max_conns=40`.
- **A4:** the A4 steps posted short and worst-case bodies
  ([load testing](load-testing.md#measurements-216-2026-10-07)).

Server snapshots are #218's counters, cumulative since that server started:
- **Before:** read before the page request;
- **After:** read after the drain, with the streams open;
- **Closed:** read 100 ms after closing them.

Peak RSS shows Caddy whenever it was running, whether or not the step used
it (— when it was not running). p95 is post-to-receipt latency, — for idle steps.
